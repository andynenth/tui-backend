🎮 Game Pieces PNG Exporter - Canvas Version

Export Castellan game pieces as PNG images with transparent backgrounds

⚠️ Important Note

This tool requires the Castellan game to be running locally or the HTML file to be served from a web server to load SVG files.

Quick Fix: Run python -m http.server 8000 in the project directory and open http://localhost:8000/game-pieces-png-exporter-fixed.html

📋 Instructions

  1. Select the piece type, color, and size below
  2. The canvas will render the piece with transparent background
  3. Right-click on the canvas and select "Save Image As..." to download
  4. Or use the "Download PNG" button (may require serving from a web server)

🛠️ Alternative Method: Manual Export

  1. Open the game in your browser: http://localhost:5050
  2. Open browser DevTools (F12)
  3. Use the element selector to select a game piece
  4. In the console, run: $0.style.transform = 'scale(3)' to make it larger
  5. Take a screenshot with a transparent background tool
  6. Or use the CSS styles from game-piece-styles.css in your own project
