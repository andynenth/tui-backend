Using These Pieces in Your Portfolio

These game pieces combine the SVG graphics with CSS styling to create the exact 3D ivory appearance from the game.
To use them in your portfolio:

  1. Copy the CSS styles for the .game-piece classes
  2. Download the SVG files from the frontend/src/assets/pieces/medieval/ directory
  3. Apply the appropriate classes: game-piece game-piece--large piece-red
  4. Insert the SVG as an <img> tag inside the game-piece div
💡 The 3D ivory effect is created entirely with CSS box-shadows and gradients - no images needed for the base!
