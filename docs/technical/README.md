# Technical Documentation

This directory contains technical documentation for the Liap-TUI project, organized by topic.

## Directory Structure

### `/join-room-fix/`
Documentation for the join room race condition fix (January 2025):
- Fix implementation plan
- Test results and performance metrics
- Production investigation guide
- Monitoring setup

### `/refactoring/`
Refactoring plans and documentation:
- Scoring system refactor plan
- Other refactoring initiatives

## Document Types

- **Fix Plans**: Detailed plans for bug fixes with implementation steps
- **Test Results**: Comprehensive test results and performance metrics
- **Investigation Guides**: Production monitoring and debugging guides
- **Refactoring Plans**: Architecture improvements and code cleanup plans

## Naming Conventions

- Use descriptive names with underscores (e.g., `JOIN_ROOM_RACE_CONDITION_FIX.md`)
- Append version numbers for major revisions (e.g., `_V2.md`)
- Group related documents in subdirectories
- Include README.md in each subdirectory for context
